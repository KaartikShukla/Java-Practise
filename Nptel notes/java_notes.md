# 1. Java Program Structure ⭐⭐⭐⭐⭐

```java
import java.util.*;

public class HelloWorldApp {

    public static void main(String[] args) {
        System.out.println("Hello World");
    }

}
```

## Important Components

| Keyword | Purpose |
|----------|---------|
| import | Imports predefined Java packages |
| public | Accessible from anywhere |
| class | Defines a class |
| static | Method belongs to class |
| void | Returns nothing |
| main() | Starting point of every Java program |
| String[] args | Command-line arguments |
| System.out.println() | Prints output on console |

> **Exam Tip:** Every Java application starts execution from the `main()` method.

---

# 2. Java vs C Program

| C | Java |
|---|------|
| #include<stdio.h> | import java.util.*; |
| printf() | System.out.println() |
| Function Oriented | Object Oriented |
| main() function | main() method inside class |

Example

### C

```c
#include<stdio.h>

int main()
{
    printf("Hello World");
}
```

### Java

```java
public class HelloWorldApp{

    public static void main(String[] args){

        System.out.println("Hello World");

    }

}
```

# 3. Java is Case Sensitive ⭐⭐⭐⭐⭐

Java distinguishes between uppercase and lowercase letters.

Correct

```java
System.out.println("Hello");
```

Wrong

```java
system.out.println("Hello");
```

Examples

```
Hello ≠ hello

Main ≠ main

System ≠ system
```

### Remember

```
Java is Case Sensitive.
```

---

# 9. Platform Independence ⭐⭐⭐⭐⭐

Java follows

```
Write Once

Run Anywhere (WORA)
```

The same `.class` file can execute on

- Windows
- Linux
- macOS
- Unix

without recompilation.

```

        │

        ▼

javac

        │

        ▼

Bytecode

        │

        ▼

JVM

        │

        ▼

Operating System
```

Each operating system has its own JVM.

The bytecode remains the same.

# 12. Java Virtual Machine (JVM)

- Executing bytecode
- Converting bytecode into machine code
- Making Java platform independent

Remember


- Digits

- Dollar ($)


### Rule 2

Cannot start with a number

❌ Wrong

```java

9abc
```

✅ Correct


### Rule 3

No Spaces

❌ Wrong


✅ Correct

```java

student_name
```

---

### Rule 4

Cannot contain commas or special symbols

❌ Wrong

```java
student,name

student-name

student@name
```

---

### Rule 5

Can be of any length

```java
a

student

studentDatabaseManagementSystem
```

---

### Rule 6

Java is Case Sensitive

```
marks

Marks

MARKS
```

All are different identifiers.

# 51. Variable Size (Jagged) Array ⭐⭐⭐⭐

Each row can have different number of columns.

Example

```java
int arr[][]=new int[3][];

arr[0]=new int[2];

arr[1]=new int[4];

arr[2]=new int[3];
```

Representation

```
Row 1 → 2 elements

Row 2 → 4 elements

Row 3 → 3 elements
```

This is called a **Jagged Array**.

# 53. Traversing 3D Array ⭐⭐⭐⭐

```java
for(int i=0;i<2;i++){

    for(int j=0;j<3;j++){

        for(int k=0;k<4;k++){

            System.out.print(cube[i][j][k]+" ");

        }

    }

}
```
